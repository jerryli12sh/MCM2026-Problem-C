
DWTS与星共舞节目共34季，每季节目中，明星与职业舞者配对，每周表演舞蹈，评委团给每对舞蹈打分，观众为当周最喜欢的组合投票（投票数量取决于每周公布的上限）。评委和观众投票合并，最低者淘汰。最终有3（或者更多）支队伍进入决赛，决赛周排名决定最终排名。

合并方式：1、2季使用按名次合并，第2季争议（Jerry Rice评委分低，但进入决赛）；3季开始按百分比合并（Bobby Bones评委分连续低但夺冠）。28季起，重新回到“名次（rank）”方式，用“评委+观众合并”确定倒数两名，然后在由评委投票决定淘汰谁。

主要的已知的数据：评委分数、选手属性；最终结果排名与每周淘汰结果
任务：
+ 估计每一次的观众投票数（推演出的淘汰结果是否和真实一致；投票数估计量的不确定性、不确定性对于不同周、选手是否一样）
+ 分析合并方式/倒二评委裁决对正义选手的的影响、结果差异、推不推荐
+ 职业舞者影响与明星特征（年龄、行业等）影响
+ 设计新规

### 不是普通预测题，而是机制反演题。

对每个赛季 $s$、每周 $t$、仍在比赛的选手集合 $A_{s,t}$，估计一个潜在观众投票份额向量 $$p_{s,t}=\bigl(p_{i,s,t}\bigr)_{i\in A_{s,t}},\qquad p_{i,s,t}\ge 0,\quad \sum_{i\in A_{s,t}}p_{i,s,t}=1.$$
观众投票信息不可观测，但它和裁判信号 $J_{i,s,t}$经过某种聚合规则后需要解释历史上谁被淘汰、谁进入决赛、谁最终排名更高。

### 两套就规则与一个新干预
题面明确存在两种把观众和裁判合并的方式：rank-based 与 percentage-based。

| 机制                      | 输入                          | 计算思想                 | 潜在倾向                       |
| ----------------------- | --------------------------- | -------------------- | -------------------------- |
| Rank rule               | 裁判名次 + 观众名次                 | 只看顺序，不看差距大小          | 压缩极端票仓；忽略“领先多少”            |
| Percent rule            | 裁判分数占比 + 观众票数占比             | 保留强弱差距的幅度            | 更忠实于强 fan base；也更容易被极端人气影响 |
| Bottom-2 + Judges' Save | 先由合成分找 bottom two，再由裁判救人/淘汰 | 观众和裁判共同定义风险区，裁判做最后筛选 | 降低技术强者被爆冷淘汰的概率             |


题目中的争议案例，例如 Jerry Rice、Bristol Palin、Bobby Bones，都指向同一个问题：如果裁判认为某人弱，但观众持续支持他，最终是否应该让ta晋级？这决定了后续模型不能只追求重现历史，还要比较制度的反事实后果。

### 任务逻辑链
1. 重建fan vote：$p_{i,s,t}$
2. 做规则回放：有了 $p_{i,s,t}$, 就可以把同一个赛季分别放进 rank、percentage、Bottom-2 save 规则中回放。
3. 解释差异来源：用选手属性、行业、年龄、partner 等解释 judge signal 与 fan signal 是否受到不同因素影响。
4. 基于历史反演和反事实回放评估 fairness 与 excitement。

## 关于数据

原始数据是选手级宽表，一行代表某个赛季的一位明星，静态列包括姓名、职业、年龄、partner、最终结果等；分数字段是 weekX_judgeY_score。

| 对象     | 检查结果                        | 含义                         |
| ------ | --------------------------- | -------------------------- |
| 原始表规模  | 421 行 × 53 列                | 421 个 contestant-season 观测 |
| 赛季范围   | Season 1 到 Season 34，共 34 季 | 每季人数和周数不同，不能硬编码统一长度        |
| 打分列    | 44 个，即 11 周 × 最多 4 位 judge  | 第四位 judge 经常缺失；周数也因赛季不同缺失  |
| 原始 0 分 | 4671 个 literal zero         | 主要不是低分，而是淘汰后的结构性填充         |
| 原始缺失   | 4741 个 NA                   | 包括没有第四位 judge、赛季未运行到该周等    |

选手被淘汰后，后续周的分数会被记为 0。这个 0 不是 judge score，而是结构占位符。因此应先定义每个赛季的真实周数 $T_s$ 和每个选手的活跃截止周 $H_{i,s}$，再把 $w>H_{i,s}$ 的 0 分重编码为缺失值。

N/A 的来源包括：该周没有第四位 judge，或者某个赛季根本没有运行到后面的周。预处理中保留原始 N/A，同时把结构性 0 转成 NaN。

results 中有 1st Place、Eliminated Week 2、Withdrew 等文本。它包含三种不同机制状态：常规淘汰、最终名次、退赛，预处理中需要拆出 elim_week_result、is_withdrew、is_place。

### 每一赛季周的选手样本空间

后续模型的基本单位为：$(s,t,i)$，分别表示赛季、周、选手。但不是所有 $i$ 都属于每个 $(s,t)$ 的竞争集合。我们必须构造 alive set：$$A_{s,t}=\{i:\ i\text{ 在赛季 }s\text{ 的第 }t\text{ 周仍然有资格被投票/淘汰}\}.$$
这一集合是整道题目的基础。观众票份额 $p_{i,s,t}$、裁判分数百分比都只在 alive set上归一化，周末淘汰者也必须来自 alive set.

### 每一赛季的长度
原始表有 Week1 到 Week11，但每季真是长度不同。判断每一季是否运行到某周：$$T_s=\max\left\{w:\exists i,\ \sum_j X_{i,s,w,j}>0\right\}.$$
其中$X_{i,s,w,j}$表示原始judge score.

### 每一选手赛季的活跃截止周
对每个选手定义活跃截止周$H_{i,s}$: $$H_{i,s}=\begin{cases}
      k,&\text{if results = Eliminated Week }k,\\
      T_s,&\text{if results is final placement},\\
      \max\{w:\sum_j X_{i,s,w,j}>0\},&\text{if results = Withdrew}.
      \end{cases}$$

然后得到资格标记：$$eligible_{i,s,t}=\mathbf{1}\{t\le H_{i,s}\}\cdot\mathbf{1}\{t\le T_s\}.$$ 这是为了明确每周仍然存活的选手集合，因为fan vote share: $$p_{s,t} = (p_{i,s,t})_{i\in A_{s,t}},\qquad p_{i,s,t} \ge 0,\qquad \sum_{i\in A_{s,t}} p_{i,s,t}=1$$ 是定义在这样的集合上面的（也就是说，fan vote不是绝对票数，而是“当周活着选手之间”的份额分布）。为什么要用份额？真实 fan vote 总量每周可能不同，而且题面也没有公开总票数。可比的对象不是绝对票数，而是同一周、同一 alive set 内的相对支持率。如果 alive set错了，fan vote 维度就错了，因此 alive set 是 fan vote inference 的前置条件。

### 由资格状态变化反推周末淘汰
对于任意选手，如果他在第 t 周仍eligible，但第 t+1 周不eligible，就说明他在第 t 周末离开：$$elim_{i,s,t}=\mathbf{1}\{eligible_{i,s,t}=1,\ eligible_{i,s,t+1}=0\}.$$
同一周离开的人按照 $(s,t)$ 聚合为一个list。特别地，决赛周的离开是赛季的自然结束，需要 is_final_week_end 标记，防止后续训练把决赛排名当作普通周淘汰。



## 核心模型：估计每一次的观众投票数

**估计每一次的观众投票数（推演出的淘汰结果是否和真实一致；投票数估计量的不确定性、不确定性对于不同周、选手是否一样）**

对于每个赛季 s, 周 t, 选手 i, 我们已经得到的三类信息：

| 对象 | 记号 | 是否观测 | 含义 |
|------|------|----------|------|
| 竞争集合 | $A_{s,t}$ | 可观测 / 预处理得到 | 第 $s$ 季第 $t$ 周仍在比赛、参与当周投票/淘汰机制的选手集合。 |
| 裁判信号 | $J_{i,s,t}$ | 可观测 / 归一化得到 | 裁判对选手的相对技术评价，必须在 alive set 内比较。 |
| 淘汰结果 | $i^*(s,t)$ | 可观测 / 事件表得到 | 单淘汰、非决赛周的真实出局选手。 |
| 观众投票份额 | $p_{i,s,t}$ | 不可观测 | 第 $t$ 周观众支持率。题目要求估计的核心对象。 |

潜在观众投票份额 $p_{i,s,t}$ 并没有真实值，只有压缩后的结果：某一周谁被淘汰，一个淘汰结果可能对应无穷组可能的fan vote, 因此第一问要做是 $$\text{find }p_{s,t}\text{ such that }\operatorname{ElimRule}(J_{s,t},p_{s,t})\approx i^*(s,t).$$
为了将无限组可能的fan vote进行压缩，我们就需要借助以下信息：
+ 跨赛季共享规律（pooled structure）：如果每一周都单独估计 fan votes，那模型可以随便编一组票，只要让真实淘汰者出局即可。这会完全过拟合。我们假设fan support 有一些夸周、跨季的共享结构：$$\eta_{i,s,t}=x_{i,s,t}^\top\beta+u_{i,s}$$ 其中$x$包括已知的个人信息、评委评分等信息，$\beta$为全体共享规律，$u_{i,s}$为选手自身的稳定人气，这作为一种稳定的人气生成机制（$\eta$表示**人气信息**）。

+ 用Dirichlet分布生成真实 fan vote 的先验分布：上一点提到的$\eta_{i,s,t}$经过某种归一化，就得到$q_{i,s,t}$均值，即结构模型认为的平均fan support（中心趋势），但真实的fan vote是一个概率分布，而不是点。如果使用点来作为$q_{i,s,t}$的估计，这会带来很多问题：观众投票天然石有噪声的，实际投票很容易收到舆论、话题、粉丝等影响偏离模型中心；统计上容易过拟合，因为$\mu$被迫解释了所有的随机扰动；淘汰结果是弱标签，不同的 p 都能导致同一个淘汰结果，因此模型是在所有可能的投票向量上做概率推断，则将$q_{i,s,t}$写成分布的形式自然更加合理。下文会介绍Dirichlet分布并说明为什么它在此情景下是合理的模型。
  

### 裁判信号 J 的处理

DWTS 跨赛季、跨周的评委数量、赛制、参赛人数都不完全一致。某周总分 27 分在三位评委下接近满分，但在四位评委或多支舞平均下未必含义相同。因此需要把裁判分数转换为当周在 alive set 内的相对信号。

1. Percentage规则下，裁判信号定义为当周分数占比，$$J^{\text{pct}}_{i,s,t}=\frac{T_{i,s,t}}{\sum_{k\in A_{s,t}}T_{k,s,t}},$$ 其中$T_{i,s,t}$为该选手当周裁判总分。
2. Rank规则下，$R_{i,s,t}$表示对同一选手被所有评委给出的排名和，越小越好，即$$R_{i,s,t}=\sum_{m\in \mathcal{J}_{s,t}}\operatorname{rank}_{m}(-\text{score}_{i,m,s,t}).$$ 
为了将Rank信息转化为一个类似于概率份额的连续变量，对$R_{i,s,t}$进行softmax归一化，$$J^{\text{rank}}_{i,s,t}=\frac{\exp(-R_{i,s,t})}{\sum_{k\in A_{s,t}}\exp(-R_{k,s,t})}.$$ 由于指数函数是下凹的，可以放大名次靠前的排名之间的差距（例如，第一名和第二名的差距大于第七名到第八名的差距），这种非线性结构是一个不差的假设。
值得注意：题目中的 Rank 机制并非使用这里的 $J^{rank}$，而是直接使用 Judge 的排序数字得到: $$CombinedRank_i=
RankJudge_i+RankFan_i$$ 这里的 softmax 变换旨在找一个统一尺度的 judge signal 来表示“技术实力”，方便将使用不同规则的所有赛季纳入同一个观众投票估计模型中。在后续使用 Rank-based 规则做历史结果回放时，采用的裁判信号定义为 $$J_{i,s,t}=\sum_{m\in \mathcal{J}_{s,t}}\operatorname{rank}_{m}(-\text{score}_{i,m,s,t}).$$ 

### 观众投票的先验均值 $q_{i,s,t}$

现在考虑如何对观众投票信息进行建模。从直觉上看：如果某个选手评委分很低，但一直没有被淘汰，那么模型就必须推断“他大概率有较强观众支持”；如果某个选手评委分不错但被淘汰，那么模型就必须推断“他观众支持可能偏弱”。

我们先假设观众支持度如何生成、然后看看这个假设能不能解释淘汰历史。

具体来说，模型先定义“**观众支持度**”：$$\eta_{i,s,t}=x_{i,s,t}^{\top}\beta+u_{i,s}.$$
这里的$\eta$是未归一化的“观众支持度”，它可以理解为“这个选手在这一周对观众的吸引力分数”。这个分数越大，模型认为他获得观众票的倾向越强。

里面用到了两类信息：
1. 观测到的信息，即$x$，包括稳定、高信号、容易解释的变量，例如当前周评委表现指标、年龄等。
2. 选手在特定赛季的人气基础，$u_{i,s}$，它是选手—赛季层面的随机截距或可正则化个体效应，用来吸收“这个明星本身就有粉丝盘、知名度、话题性、亲和力”等数据中没有直接测量的东西。比如 Bobby Bones 的真实粉丝动员能力不一定能由评委分和年龄解释，那么 u 就承担这部分长期稳定的人气差异。

因此“观众支持度”被拆成两部分：可观测的共同特征（$\beta$为全局规律），和明星个体影响力残差（选手自己的长期偏离）。

为了让“观众支持度”在不同周、赛季可比，对它进行 softmax 归一化：$$q_{i,s,t}=\frac{\exp(\eta_{i,s,t})}{\sum_{k\in A_{s,t}}\exp(\eta_{k,s,t})}.$$
这是为了确保每一周的观众投票比例$q_{s,t}=(q_{1,s,t},q_{2,s,t},\dots,q_{n,s,t}),$满足$$q_{i,s,t}>0,\qquad \sum_{i\in A_{s,t}}q_{i,s,t}=1.$$
由于观众投票是相对竞争，一个选手在本周的观众投票情况受制于通常其他人有多强，因此分母必须对 alive set 求和，$q_{i,s,t}$要用相对概率表示，而 softmax 只关心相对差异。

### 表示淘汰概率

有了 $J$ 和 $q$，模型需要把“谁被淘汰”变成一个概率。DWTS 的规则逻辑是 combined score 越低越危险，因此定义：$$C_{i,s,t}=J_{i,s,t}+q_{i,s,t}.$$
那么应该淘汰谁？如果完全确定性地建模，我们可以写：$$i^*(s,t)=\arg\min_{i\in A_{s,t}} C_{i,s,t}.$$
但这样太硬，现实中 DWTS 的规则有很多不确定因素：分数并列、排名规则变化、制作机制、观众动员、数据噪声、特殊赛制、节目叙事等。更重要的是，我们推断出来的 q 本来就是一个近似趋势，不应该要求它每周 100% 精确地产生淘汰者。
所以模型使用 softmin choice likelihood:
$$\Pr(i^*(s,t)=i\mid A_{s,t})=\frac{\exp(-C_{i,s,t}/\tau)}{\sum_{k\in A_{s,t}}\exp(-C_{k,s,t}/\tau)}.$$
C越小、$\tau$越小、被淘汰的可能越高。这里的$\tau$是temperature，控制模型有多确定。

### 如何学习“观众支持度”：$\eta_{i,s,t}=x_{i,s,t}^{\top}\beta+u_{i,s}$ 中的系数 $\beta$

如果确定候选参数$\Theta=\{\beta,u,\tau\}$，模型都可以算出每个人的$\eta$，再得到 q，进而得到真实淘汰者$i^*$被淘汰的概率$$\Pr_\Theta(i^*(s,t)\text{ eliminated}).$$
把所有周相乘，就得到似然：$$L(\Theta)=\prod_{(s,t)\in\mathcal T}\Pr_\Theta(i^*(s,t)\text{ eliminated}\mid A_{s,t}).$$其中，$\tau$包含所有非决赛、单淘汰的周，$i^*(s,t)$为第(s,t)周被淘汰的人。

目标是 $\boxed{\hat\Theta=\arg\max_\Theta \ell(\Theta)}$，即找一组参数，让真实发生的淘汰事件出现概率最大。优化目标就是最大真实淘汰事件的似然，也就是“所有观测到的淘汰事件 $(s,t,i^∗)$ 的概率乘积”。

代入 softmin choice likelihood 并改成负对数形式：$$-\ell(\Theta)=\sum_{(s,t)\in\mathcal T}\left[\frac{C_{i^*,s,t}}{\tau}+\log\sum_{k\in A_{s,t}}\exp(-C_{k,s,t}/\tau)\right].$$
含义是：如果真实淘汰者的 C 很低，那么 softmin 会给他很高的淘汰概率，loss很小，反之亦然。优化器会调整 $\beta$和$u$，让真实淘汰结果变得更合理。

关于正则化：如果只最大化 likelihood，模型很容易走向过拟合。原因是每个选手都有一个 u，而历史淘汰结果又是固定的。模型可能通过把某些选手的 u 调得极高或极低，强行解释每一次淘汰。比如某个选手评委分很低但一直没被淘汰。没有正则化时，模型可以把他的 u 调得非常大，说“这个人观众支持无限强”。所以应该增加正则项：$$\mathcal L(\Theta)=-\ell(\Theta)+\lambda_\beta\|\beta\|_2^2+\lambda_u\|u\|_2^2.$$

## Dirichlet 后验更新：从平均趋势$q$到当周票份额$p$

前一部分点估计已经给了一个“平均观众支持趋势”，它来自于评委表现、年龄、选手固定人气等结构信息。但真实投票不能直接等同于$q$。原因是：观众投票有强烈的周波动。一个选手可能某周跳得特别好，突然被大量投票；也可能因为话题争议、剪辑、粉丝动员、社媒传播而在某周异常升高或降低。为了捕捉真实投票的随机变动，需要把观众投票看作一个随机向量，并根据真实淘汰情况进行更新。

$q$是模型根据历史规律、评委表现、年龄、静态人气等信息推出来的“趋势中心”，是在全历史数据上学到的“平滑趋势”，他只告诉你中心预测，且没有充分利用“这一周的淘汰者”作为周级证据。

所以问题变成了：$$\text{已知 }q,J,Y=i^*,\text{ 求 }p\text{ 的后验分布。}$$
也就是 $$\pi(p\mid Y=i^*,q,J).$$

### 真实粉丝投票情况p的先验分布

我们使用 Dirichlet 分布来表示真实投票情况的概率分布：$$p_{s,t}\sim \text{Dirichlet}(\alpha_{s,t}),$$其中$\alpha_{s,t}=\kappa q_{s,t}.$

为什么是 Dirichlet? 它用于描述“若干类别的比例份额”、比例向量。如果我们用正态分布建模 p，会遇到诸多问题：可能生成负数、各分量和不为1、不同选手投票份额独立，这显然不符合事实（任意两个选手的投票份额应当呈现负相关），而 Dirichlet 分布天然满足这些条件。

如果 $$p\sim \text{Dirichlet}(\alpha_1,\dots,\alpha_n),$$
那么$$E[p_i]=\frac{\alpha_i}{\sum_k \alpha_k}.$$
我们希望这个先验分布的均值等于q。在本例中$E[p_i]=\frac{\kappa q_i}{\kappa}=q_i.$ 意思是，“在没有进一步周级证据之前，我相信真实投票 p 会围绕 q 波动。”

$\kappa$是 concentration parameter, 控制 p 围绕 q 的紧密程度。当 $\kappa$ 很大的时候，Dirichlet 分布很集中，反之亦然。

### 用淘汰事件更新后验

如果真实观众票是某个候选向量 p，那么观察到 $Y = i^*$的概率是多少？

已知对于真实观察到的淘汰者，似然函数是：$$L(p)=\Pr(Y=i^*\mid p,J)=\frac{\exp(-(J_{i^*}+p_{i^*})/\tau)}{\sum_{k=1}^n \exp(-(J_k+p_k)/\tau)}.$$
淘汰结果告诉了我们哪些 p 更合理，哪些更不合理。

由贝叶斯公式，已知似然和先验，可以得到后验：$$\pi(p\mid Y=i^*,q,J)=\frac{\Pr(Y=i^*\mid p,J)\pi(p\mid q)}{\int_{\Delta^{n-1}}\Pr(Y=i^*\mid p',J)\pi(p'\mid q)\,dp'}.$$ 其中分母是归一化常数。带入似然函数和先验分布函数，可以得到：
$$\pi(p\mid Y=i^*,q,J)\propto\left(\prod_{i=1}^n p_i^{\kappa q_i-1}\right)\cdot\left[\frac{\exp(-(J_{i^*}+p_{i^*})/\tau)}{\sum_{k=1}^n \exp(-(J_k+p_k)/\tau)}\right].$$
在这个阶段，q是先验分布的参数，p是我们真正想推断的隐藏变量。我们最后得到的观众投票情况是后验均值：$$\hat p_i=E[p_i\mid Y=i^*,q,J].$$

梳理清楚：
+ **候选变量** $ q_{i,s,t} = Softmax(\eta_{i,s,t})=Softmax(x_{i,s,t}^{\top}\beta+u_{i,s})$ 只用到了s季t周i选手的个人属性，以及当期的 Judge 评分，参数是在所有季的数据上由joint likelihood MLE得到的，其中每一个$(s,t)$ 周的likelihood是真实淘汰着 $i^*$ 在 alive set 中被淘汰的概率；
+ **投票先验分布** $p_{s,t}\sim \text{Dirichlet}(\kappa q_{s,t})$ 以候选变量 $q_{i,s,t}$ 为中心做了一个投票分布的假设
+ **似然函数** $L(p)=\Pr(Y=i^*\mid p,J)=\frac{\exp(-(J_{i^*}+p_{i^*})/\tau)}{\sum_{k=1}^n \exp(-(J_k+p_k)/\tau)}$ 表示在真实投票为 $p_{s,t}$ 的情况下，已观察到的淘汰结果 $i^*$ 的密度。
+ **后验分布** $\boxed{\pi(p|i^*,J) \propto Pr(Y = i^*|p,J)
\times
Dirichlet(p|\kappa q)
}$


### Importance Sampling估计

现在问题变成了：如何解这个后验。由于 Dirichlet density 和 softmin likelihood的乘积没有解析解，需要用Importance Sampling估计。

具体来讲：
从先验中抽很多候选投票向量：$$p^{(1)},p^{(2)},\dots,p^{(B)}\sim\text{Dirichlet}(\kappa q).$$ 
然后对每个样本$p^{(b)}$，计算它解释真实淘汰的能力：$$w^{(b)}=\Pr(i^*\text{ elim}\mid p^{(b)})=\frac{\exp(-(J_{i^*}+p^{(b)}_{i^*})/\tau)}{\sum_k \exp(-(J_k+p^{(b)}_k)/\tau)}.$$
归一化权重：$$\tilde w^{(b)}=\frac{w^{(b)}}{\sum_{m=1}^B w^{(m)}}.$$
最后用加权样本估计：$$\pi(p\mid Y)\approx\sum_{b=1}^B \tilde w^{(b)}\delta_{p^{(b)}}(p).$$
这里 $\delta_{p^{(b)}}(p)$ 为集中在样本点 $p^{(b)}$ 上的点质量，得到了经验分布函数（用于近似理论连续分布）。

### 为什么要用两次评委信息？淘汰事件也用了两次。

评委信息在两个地方出现：$q_{i,s,t}$和$p_{i,s,t}$，分开看：
1. $q_{i,s,t}$是选手-周级别的“观众支持度”，其使用的特征均为当周信息，包括当周裁判信息$J_{i,s,t}$，表示：观众可能会受到舞蹈表现/评委评价相关信号影响。（这里做了一个强假设：评委是从专业技术/舞蹈表现的角度进行打分，蕴涵了参赛者技术水平的信息）。
它回答的是：“在这一周，考虑该选手的表现、年龄、静态人气等信息后，观众票大概会怎么分布？”
也就是说，$J_i \uparrow \Rightarrow q_i \uparrow$（观众可能也更喜欢他，因为他跳得好。）
1. $p_{i,s,t}$是选手-周级别的“观众投票比率”，节目规则中评委分本身和观众投票比率共同决定淘汰信息。
它回答的是：“给定真实淘汰者，哪些真实观众票 p 能解释这个淘汰结果？”
也就是说，$J_i \uparrow \Rightarrow C_i=J_i+p_i \uparrow \Rightarrow \text{淘汰风险下降}$（即使观众票不变，评委分本身也会保护他）

评委信息在现实机制中有两个通道：表演质量既可能影响观众投票，也直接影响官方综合分。所以这不是重复计算。

关于淘汰事件：在估计q的时候用了一次，在更新p的时候又用了一次。更好的思路如下：
$$p_{s,t}\sim Dirichlet(\kappa q(\beta,u))$$
$$Y_{s,t}\sim Softmin(J+p)$$
$$P(Y|\beta,u)=\int P(Y|p,J) Dirichlet(p|\kappa q)dp$$
然后直接估计$\beta,u$，这样就不会重复使用信息了。

## 模型评估：估计的粉丝投票是否能准确、确定？

根据我们预估出来的观众响应，可以得到合并后的总成绩数据，在末位退出的制度下就能预测每轮的淘汰者：$$\hat i(s,t)=\arg\min_{i\in A_{s,t}}\hat C_{i,s,t}.$$其中$$\hat C_{i,s,t}=J_{i,s,t}+\hat p_{i,s,t}.$$
那么“淘汰结果的预估精度”就可以用 **Top-1 accuracy（预测淘汰者的准确度）** 表示：$$A=\frac{1}{|\mathcal{T}|}\sum_{(s,t)\in\mathcal{T}}\mathbb{1}\{\hat i(s,t)=i^*(s,t)\}.$$

不过只有模型的预估精度还不够，我们需要一个基准模型对比来衡量模型的好坏。我们使用了XGBoost模型用来预估每周的淘汰情况，使用了“周-选手特征”（评委评分、选手年龄等可观测特征，而 fan vote 不在考虑范围内）

但值得注意的是：由于模型在构造p的时候存在最终结果的暴露，因此accuracy只能表明它构造出来的潜在 fan votes 更能解释历史淘汰序列。

但这还不够。显然，真实淘汰者被模型风险排序在第二位和排序在第八位所代表的准确度肯定是不同的，前者更准确些。一个自然的问题是，**如果我从第一周开始一直用模型淘汰，会不会重建整个赛季？** 为了刻画“模型重建整个淘汰轨迹是否合理”，令 $E_{s,k}$为赛季s前k个被淘汰的人，$\hat{E}_{s,k}$ 为根据模型输出的赛季s前k个被淘汰的人。只要计算到第k个被淘汰的人为止，模型恢复了多大比例的淘汰，即 $\frac{n'_{s,k}}{n_{s,k}}$, 其中 $$n_{s,k}=|E_{s,k}|$$ 表示真实淘汰数量，$$n'_{s,k}=|E_{s,k}\cap \hat E_{s,k}|$$ 表示模型正确恢复数量。

对于赛季s的综合表现，使用时间加权（即 Harmonic Normalization） $$S_s=\frac1{H_{K_s}}
\sum_{k=1}^{K_s}
\frac1k
\frac{n'_{s,k}}{n_{s,k}}$$
其中 $H_{K_s}=
\sum_{k=1}^{K_s}\frac1k $
这个加权想法源自调和平均 (Harmonic Mean)：$H(x_1,\dots,x_n)=
\frac{n}
{\sum_{i=1}^{n}\frac1{x_i}}$, 调和平均起到了降低高分权重，提升低分影响的作用；在这里的作用为提升赛季早期比赛周的影响，因为越早发生的错误影响越大。
所有赛季加权的结果为$\bar S=0.78$，这表明整体淘汰路径有较高的一致性。

前两个指标都只考虑了$\hat C_{i,s,t}=J_{i,s,t}+\hat p_{i,s,t}$最小的选手作为当周淘汰对象，但事实上淘汰具有随机性，淘汰结果是以概率分布（直接由模型中观众投票的后验分布得到）呈现的。因此我们在这个分布中独立抽样 $b$ 次，每一次预测淘汰 $\hat i^{(b)}=
\arg\min_i(J_i+p_i^{(b)})$, 定义 $$PCP=
\frac1B
\sum_b
I(\hat i^{(b)}=i^*)$$ PCP 表明后验里面有多少比例认为真实淘汰是合理的。数据表明存在 Crowded Field Effect，即 PCP 指标随 Alive Set 内元素数量的减小而增大。也就是说，参赛选手越多，预测淘汰者越难。

对模型不确定性的评估在贝叶斯模型下体现为 Credible Interval(可信区间)：$$CI_{90}=
[Q_{0.05}(p),
Q_{0.95}(p)]$$ 定义相对宽度：$$RW = 
\frac{Upper-Lower}{\hat p+\epsilon}$$ 如果可信上限和下限的相对差距较小，说明结果的确定性较好。数据显示，随着 Alive Set 元素减少，总体的不确定性减轻；头部选手往往由更好的确定性。

## 评估不同的票数合并机制对结果的影响

由模型得到后验观众投票分布 $p_{s,t}$，结合裁判已有信息 $J^{rank}_{i,s,t}$ 或者 $J^{perc}_{s,t}$，分别使用 Rank-based Rule 和 Percentage Rule 实现裁判和观众信息的聚合。聚合方式分别为：
$$Rank-based: Score_i=Rank^J_i+Rank^F_i$$
$$Percentage-based: Score_i = J_i^{pct}+p_i $$
要判断哪种制度更偏向粉丝，可以看每一个完整机制的淘汰者 $e_m$ 和只使用评委信息得到的淘汰者 $e_J=
argmin(J_i)$ 不同的比例: $$Override_s^m=
\frac1{|W_s|}
\sum_t
I(e^m\neq e_J)$$

结果是 Percentage-based Rule 的 Override更高，意味着更容易出现 fan-driven override.

加入 Bottom-2 机制后会发生什么变化？新的机制为先让裁判与观众共同决定倒数两位淘汰候选，再完全由裁判决定淘汰者。引入这个机制带来的变化可以量化为 $$rev=
P(
Bottom2+Save
\neq
Direct elimination
)$$
模拟结果可以得出：Percentage 下的 reversal 更高，随着 Alive Set的缩小，reversal平均增高。

再关注争议群体，他们都有一个共性：裁判评分远低于观众受欢迎度。为了直观呈现 Jerry Rice, Billy Ray Cyrus, Bristol Palin, Bobby Bones 这四位选手在总体选手中“受观众欢迎大雨裁判评分”的特性，将每一位选手放在二维平面内，x轴定义为 fan rank - judge rank, y轴定义为 fan share - judge share, x轴只关注 rank，y轴刻画 $\Delta s=
\hat{p}-J$, 显然“受观众欢迎大于裁判评分”的选手都在第二象限，也更容易受到 Bottom-2 机制的影响，增加被淘汰概率。

到底要选择哪种合并制度呢？一共有四种选项，rank还是percentage, 是否采用bottom-2。好的制度应该同时保留观众参与感，并防止极端粉丝优势导致明显技术弱的选手长期存活。
定义$$x =  Fan Influence =\mu(|\Delta_s|) =\mu(|p_i-J_i|)$$ 表示观众支持和裁判评价之间存在多大程度的不一致（fan signal 和 judge signal 的分离程度）。
定义 $$y=1-\mu(|\Delta_r|)=1-\mu(|r_{Final}-r_J|)$$ 表示最终竞争结果越符合裁判对于技术能力的判断。
结果表明，这四种制度中，Perc+Bottom2 的选项总体的x和y都是最高的，意味着观众和评委的打分分歧大（制造悬念和节目效果），且最终淘汰者和评委选出的最低分一致性最高（防止极端粉丝优势导致明显技术弱的选手长期存活）。

## 设计新的机制

第四问让我们设计一个更“公平”（或更刺激、更好看等）的新系统，用评委分与观众投票每周决定淘汰。这是一个机制设计问题，它和前面最大的区别在于：前面是在解释 DWTS 这个系统为什么产生历史结果，第四问是反过来设计一个新的规则，希望改变未来结果。那么核心问题就变成了：
> 已知历史系统存在“技术实力（judge signal）”和“公众偏好（fan signal）”之间的冲突，我们如何设计一个新的淘汰机制，在公平性（fairness）和娱乐性（excitement）之间取得更好的平衡？

这一问要定义什么是“更好的机制”，提出候选机制，并用第一问观众投票后验分布的结论做 Monte Carlo 反事实模拟得到机制的长期后果，比较并推荐最终规则。

首先定义公平和娱乐性：

DWTS是技术和人气相结合的比赛，因此公平定义为“不应该出现技术优秀选手因为随机粉丝因素过早淘汰”，用 Technical Shock Rate 表示：
$$Shock_k=
Pr(elim(s,t)\in Top-k\ judges)$$
如果一个选手在 judge ranking 中属于前 k 名，但是被淘汰，这是一个参数为k的技术冲击。

娱乐性主要体现在观众参与感上，核心是“fan vote 必须能够改变结果”，意味着$Var(outcome|fan)$应该足够大。

我们的思路主要是：弱化高粉丝票数，强化评委响信号，拉开技术差距。利用幂函数的凹凸性做如下变换：
$$\tilde p_i=
\frac{p_i^\gamma}
{\sum_k p_k^\gamma}, 0<\gamma<1$$
$$\tilde J_i=
\frac{J_i^\delta}
{\sum J_k^\delta}, \delta>1$$

此外，比赛不仅看当前表现，将一季比赛的演进看作参赛者的成长过程，提出 Momentum Bonus，为技术进步的人提供奖励加成。定义

$$ m_{i,t}=
T_{i,t}
-
\frac1L
\sum_{\ell=1}^{L}T_{i,t-\ell}$$ 

即当前表现 - 最近平均。然后进行变换 $$B_i=
\mu\tanh(z_i/c)$$，使用tanh函数是为了在小提升时提供明显奖励，随着提升增大，奖励趋近饱和。

得到最终机制 $$S_i=
w_J\tilde J_i
+
w_F\tilde p_i
+
B_i$$
然后采用 Bottom-2 Judges Save 政策，决定淘汰者。这套方案能够有效降低极端粉丝统治；保留观众参与；保护技术强者。

## 机制解释
第三问探究**职业舞者影响**与**明星特征（年龄、行业等）影响**。为什么某些选手能够在比赛中长期存活？这种优势到底来自技术实力、明星自身属性、粉丝号召力，还是职业舞伴带来的帮助？这些因素对“最终走多远”影响多大？对评委分与观众票的影响是否一致？

我们将 survival 拆分成两部分因素：$$Celebrity/Partner\ Characteristics
\rightarrow
\begin{cases}
Judge\ Performance\\
Fan\ Support
\end{cases}
\rightarrow
Survival$$

但我们并不能直接把 Judge Score 放到回归模型里。因为 DWTS 的评分环境不断变化：不同赛季的 Judge 数量不同、选手数量不同、后期比赛整体分数较高、评分标准可能漂移......

因此我们统一取 Judge Rank，将 Rank 转换为percentile，并进行正态映射： $$Z^J_{i,t}=
\Phi^{-1}
\left(
1- 
\frac{R^J_{i,t}-0.5}{N_{s,t}}
\right)$$
对每个 season-week 单独进行：$R^J_{i,t}
\rightarrow
Z^J_{i,t}$, 这个$Z^J$可以跨赛季比较。当然，这里做了前提假设：每一季同期选手总体实力/评委信息分布相当，且均符合同一正态分布。

明星属性为什么影响 Judge 和 Fan 的不同？建立两个平行模型:
$$Y^{type}_{i,t}=
\alpha
+
\beta^{type}_{Age}Age_i
+
\sum_k
\delta^{type}_k I(Industry_i=k)
+
\epsilon, type\in\{Judge,Fan\}$$

结果显示，对于Judge, $\beta^J_{Age}\approx -0.04$，可以解释为年龄增加导致身体机能下降；对于 Fans，$\beta^F_{Age}$ 为正；Actor 早期在 Judge 角度有优势（$\beta\approx0.16$），到了中期 Fans 角度反而下降（$\beta=-0.87$），这可能与高心理预期未能持续满足有关。

除了静态属性，选手的“突然突破”同样能影响评分。这种 Surprise 定义为

$$S_i=
Z^{Judge}_{i,t}
-
Z^{Fan}_{i,t-1}$$
如果当前技术表现远高于之前观众支持水平，说明参赛者在超预期表现。

定义 Fan Growth，粉丝支持变化：

$$G_i=
Z^{Fan}_{i,t}
-
Z^{Fan}_{i,t-1}$$

$$G_i
=
\beta_0
+
\beta_1S_i
+
\beta_2S_i^2
+
\epsilon$$

使用了二次项，是考虑到巨大的突破会产生爆炸式增长，形成故事传播，支持 Fan support。

总结：这部分分析思路整理为$$\boxed{
Celebrity\ Attributes
\rightarrow
Judge/Fan\ Pathways
\rightarrow
Survival
}$$
