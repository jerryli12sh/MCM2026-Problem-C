# 方法说明

## 1. 数据单位与在赛名单

原始数据一行表示一个“选手—赛季”，共有 421 行、53 列，其中 44 列为 `week{t}_judge{j}_score`。同一名选手跨季参赛时保留不同记录。

对赛季 $s$，以仍存在正评分的最后一周确定赛季长度 $T_s$。选手的在赛截止周 $H_{i,s}$ 按比赛结果解析：正常淘汰取淘汰周，获得最终名次者取 $T_s$，退赛者取最后一个正评分周。于是

$$A_{s,t}=\{i:t\leq H_{i,s},\ t\leq T_s\}.$$

淘汰后的 0 分作为结构性填充值处理；未设置第四位评委、该季未播出的周次保留为缺失。退赛、多淘汰周与决赛分别标记。训练及主要 Top-1 评价使用 **218 个正常单人淘汰周**，事件表另外保留其他退出情况。

原始数据展开得到 4,199 行周面板，包含在赛与退出标志；周后验表包含 2,780 行有效选手—周记录。全体数据覆盖 34 季，主要单人淘汰周评价覆盖其中 33 季。

## 2. 观众支持度模型

### 符号

| 符号 | 含义 |
|---|---|
| $s,t,i$ | 赛季、周、选手 |
| $A_{s,t}$ | 当周在赛选手集合 |
| $J_i$ | 在当周名单内归一化的评委信号 |
| $p_i$ | 潜在观众支持份额，$p_i\geq0,\sum_i p_i=1$ |
| $q_i$ | 模型拟合的支持度中心 |
| $x_i,\beta$ | 选手特征与共享系数 |
| $u_{i,s}$ | 选手—赛季效应 |
| $e_{s,t}$ | 当周实际淘汰者 |
| $\kappa$ | Dirichlet 集中度 |
| $\tau$ | 淘汰 softmin 温度 |

特征包括标准化评委信号、规则年代指示和年龄；年龄在一个选手—赛季内不变，选手效应能够吸收其中一部分信息。支持度中心为

$$q_i=\frac{\exp(x_i^\top\beta+u_{i,s})}{\sum_{j\in A_{s,t}}\exp(x_j^\top\beta+u_{j,s})}.$$

共享截距在 softmax 中相消，代码保留该参数以对齐原实现。周支持度满足

$$p\sim\operatorname{Dirichlet}(\kappa q).$$

给定支持度与评委信号，淘汰似然为

$$L(e\mid p,J)=\frac{\exp[-(J_e+p_e)/\tau]}{\sum_{j\in A_{s,t}}\exp[-(J_j+p_j)/\tau]}.$$

### P：两阶段估计

1. 将 $p$ 替换为中心 $q$，拟合带 L2 惩罚的淘汰负对数似然。
2. 对每一周抽取 $B$ 个 Dirichlet 样本 $p^{(b)}$。
3. 按观测淘汰者的似然计算归一化权重 $w_b\propto L(e\mid p^{(b)},J)$。
4. 用 $\widehat p_i=\sum_b w_b p_i^{(b)}$ 得到后验均值，以加权分位数给出 90% 可信区间。

拟合使用 NumPy 实现的 Adam，保留原方案的 float32 训练与固定随机种子；后验汇总使用 float64。

### R：边际似然估计

R 对潜在支持度积分后拟合：

$$\mathcal L(\beta,u)=\prod_{s,t}\int L(e_{s,t}\mid p,J)\operatorname{Dir}(p;\kappa q(\beta,u))\,dp.$$

积分通过蒙特卡洛近似，梯度使用 Dirichlet score-function 估计，并记录蒙特卡洛标准误与有效样本量。该模型把参数拟合与周后验放在同一概率结构中。

### 两条路线的规则年代划分

| 赛季 | P：原代码计算口径 | R：题面口径 |
|---|---|---|
| 1–2 | Rank | Rank |
| 3–27 | Rank | Percentage |
| 28–34 | Percentage | Rank |

这里的年代划分决定推断模型中的 $J$：Percentage 使用评分占比；Rank 使用各评委名次之和的负值经 softmax 归一化。R 中第 28 季回归排名制采用题面建议的时间假设。P 保留原计算口径，保证原方案结果可重建。

因此 P/R 的并列比较同时包含估计方法与年代划分两项差异。单独识别某项差异的影响，需要固定另一项重新拟合。问题二中的离散规则回放则直接实现名次相加与占比相加，与推断阶段的连续评委信号分开。

### 默认参数

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `seed` | 42 | 拟合与采样随机种子 |
| `tau_train` | 0.05 | 中心拟合温度 |
| `tau_like` | 0.15 | 后验更新温度 |
| `kappa` | 10 | 周支持度集中度 |
| `l2_beta`, `l2_u` | 0.05, 0.05 | 特征与选手效应惩罚 |
| `lr` | 0.02 | Adam 学习率 |
| `n_steps`, `batch_size` | 600, 32 | 迭代次数与批大小 |
| `B` | 1,200 | 每周后验采样数 |
| `alpha_floor` | 0.1 | R 的采样梯度数值稳定下界 |

P 从 `configs/problem1.yaml` 读取参数；R 使用 `Problem1Config.for_track("R")`，完整拟合参数随结果保存。修改 P 的 YAML 不会自动改动 R。

## 3. 评价指标

- **Top-1 重构率**：在正常单人淘汰周中，$\arg\min_i(J_i+\widehat p_i)$ 与实际淘汰者一致的比例。P 为 207/218，R 为 182/218。
- **PCP**：在后验抽样下，实际淘汰者对应最小综合得分的概率，使用重要性权重汇总。
- **ESS 比例**：$1/(B\sum_b w_b^2)$，刻画重要性权重的集中程度。
- **相对区间宽度**：支持度 90% 可信区间宽度除以后验均值，使用数值下界稳定小均值。
- **赛季路径一致性**：从事件层的概率与生存路径得到每季一致性，再跨赛季平均，具体实现位于 `problem1/evaluate.py`。

Top-1 按淘汰周平均；README 的 PCP、ESS 和区间宽度读取 `summarize_posterior` 的选手—周汇总。相同周的 PCP 在选手行重复，因此该汇总会赋予在赛人数多的周更高权重；逐周均值另存于 `problem1_top1_by_week_*.csv`。

上述结果的用途是历史淘汰重构与支持度解释。P 的参数拟合和周更新都使用已观测淘汰；R 的周后验也以历史淘汰为条件。

## 4. 投票规则回放

- **Rank**：将评委名次与观众支持度名次相加，综合名次最差者淘汰。
- **Percentage**：将评委评分占比与观众支持份额相加，综合占比最低者淘汰。
- **Bottom-2 + Save**：先按上述综合规则确定末两位，再淘汰其中评委表现较差的一位。

`problem2/rules.py` 统一处理排序、并列及裁决规则。`problem2/replay.py` 逐周计算规则分歧、反转概率和案例路径。规则比较同时使用点估计和后验抽样，默认抽样次数为 600 或 1,200，保存在相应汇总文件中。

赛季路径回放中，改变淘汰规则会使部分选手留到原数据未记录的后续周。此时沿用最后一次观测到的评委/观众信号；多淘汰周和其他特殊周按实现中的观测退出逻辑处理。这一设定使各规则能够在共同的历史条件下比较。

## 5. 选手与舞伴分析

输入为预处理生成的 `data/intermediate/data_3.csv`。该表连接官方最终名次与原分析的评委/观众标准化信号，共 392 个选手—赛季，剔除了退赛者、第 1 季及全明星第 15 季。`placement_z` 以真实名次计算本季击败比例后标准化；评委阶段特征沿用最近的有效评分，观众阶段特征保留原分析的估计与缺失。

分析包括：

1. 属性 OLS：年龄、行业及国家/地区分类，使用 HC3 稳健标准误；另加赛季固定效应。
2. 舞伴历史特征：此前赛季的名次、夺冠率、前三率与参赛次数。
3. 方差解释与前向验证：比较特征增量，并按赛季时间顺序训练/评价。
4. Surprise/Growth：构造预期落差与后续表现，拟合线性、二次与经验交互项。

这些模型刻画观测属性和模型估计信号之间的关联。固定效应模型遇到只出现一次的舞伴时，HC3 方差可能不稳定；对应舞伴系数主要用于描述。表中保留样本量与标准误，方便按实际估计精度解读。

## 6. 赛制设计与模拟

每种规则每季进行 300 次模拟，共 34 季、5 种规则，即 **51,000 条模拟赛季路径**。

第一组中，`S1` 按 0.5/0.5 加权名次选择末两位并由评委裁决；`S2` 前 8 次淘汰采用 S1，之后从评委最差的 3 人中淘汰观众支持最低者；`S3` 全程采用这组三人风险集规则。第二组 `V4/V5` 比较加权占比基线与改进方案。代码名称保留原实现，论文的“Mechanism II / V2”对应这里的 `V5`。

改进方案使用

$$\widetilde p_i=\frac{p_i^{\gamma}}{\sum_jp_j^{\gamma}},\quad
\widetilde J_i=\frac{J_i^{\delta}}{\sum_jJ_j^{\delta}},\quad
C_i=0.8\widetilde J_i+0.2\widetilde p_i+b_i.$$

默认 $\gamma=0.45,\delta=1.35$，$b_i$ 为最近两周表现的有界奖励，尺度参数为 0.01。之后在最低两位中应用评委拯救。基线 `V4` 使用相同 0.8/0.2 权重与 Bottom-2，但采用未经幂变换的信号，也不加表现奖励。

模拟每周从拟合中心对应的 Dirichlet 分布抽取观众份额。选手留存超出实际退出周时采用上一评分或赛季均值补全技术信号；结果按这一共同模拟环境解释。

`Shock_k` 记录评委排名前 $k$ 的选手被淘汰的频率；案例结果给出各周留存、平均综合名次与末周留存。`alive_rate` 表示当周入场者中的未淘汰比例，`final_alive_rate` 表示案例汇总定义下的最后可见周留存，具体分母见数据说明。

## 7. 稳健性设计

| 组别 | 变化内容 | 读取的变化 |
|---|---|---|
| A1 | 拟合温度、Dirichlet 集中度 | PCP、重构率、区间宽度、支持度排序 |
| A2 | 选手效应与特征系数的惩罚比例 | 解释结构与后验稳定性 |
| A3 | 评委信号采用不同 softmax 温度或百分位 | 结果对评分尺度的依赖 |
| A4 | 每次剔除一个赛季并重新拟合 | 剩余样本上的重构与排序稳定性 |

A4 是逐季剔除的样本稳定性检验，评价在保留的赛季上进行；按时间前向验证另由属性回归模块提供。
